Can Chrome run several Arabic dialects at once?

The Web Speech API takes a dialect as an input — you tell it ar-EG and it decodes as if you were Egyptian. It never reports which dialect it heard. The only way to turn that into a detector is to run every dialect over the same speech and see which transcript comes out cleanest.

It only accepts a live microphone, so this is the one thing that might work: five recognisers started at once on the same mic. Nobody documents whether Chrome allows that. Speak Arabic for ten seconds and find out.
